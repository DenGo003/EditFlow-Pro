# Source and compatibility audit — 0.9.6

## Update button, 0.9.6

Premiere 25.6.2 UXP's panel talks only to the authenticated loopback backend. The backend checks the existing GitHub Releases latest endpoint by default, compares it with a newer exact-name ZIP in Downloads, and permits an optional custom HTTPS feed. It caps download/archive sizes, rejects unsafe paths and symlinks, checks the release target/version and every manifest hash, then stages a detached worker. The worker waits for Premiere and the old backend to close, uses the existing reversible installer, writes persistent status and keeps the previous release. The one-click gesture cannot replace live plugin files or force Premiere to save a project; user closes Premiere after saving. The host path has not run on Windows here. The Release asset digest or optional feed SHA256 is integrity checking, not a publisher signature; only trusted HTTPS hosting should be configured.

## Original motion and sound pack, 0.9.4

Premiere 25.6 UXP documents `ComponentParam.createSetTimeVaryingAction`, `createKeyframe`, `createAddKeyframeAction`, `getKeyframeListAsTickTimes` and `getValueAtTime`, plus selection and project transactions. The Motion tool limits application to a single direct video clip with unanimated native Scale and checks the selected project/sequence/source/timing/track/scale again at Apply. It uses two Premiere transactions (enable animation, add all keys), then reads keys back. Native timeline behavior and keyframe time coordinates still need a 25.6.2 acceptance test.

The packaged PCM WAV files are generated by our own reproducible synthesis script. Adobe's 25.6 API documents SourceMonitor.openFilePath/play, Project.importFiles and SequenceEditor.createInsertProjectItemAction. The Sound Library previews without timeline edits, imports/reuses one project item and requests insertion on a new audio track at the active playhead. It verifies new track and media position; Premiere's live insertion/ripple behavior still needs host validation on a copy of a sequence. There is no EditFast media/service dependency.

## Search & Markers, 0.9.3

The official Premiere 25.6 reference documents `TickTime.createWithSeconds`, `Sequence.setPlayerPosition`, `Markers.getMarkers/createAddMarkerAction`, `Project.lockedAccess/executeTransaction`, and `Marker.getName/getStart`. The new panel uses these 25.6 methods, creates native sequence Comment markers inside a single undoable transaction and checks readback. Its generated transcript gets actual word start times from the existing local Whisper pass; selected external SRT files supply cue starts only. Marker names and comments originate from user transcript text and are never sent to an external service. Existing grade, tracks and captions are not changed by this feature.

The UXP markup, JavaScript and backend passed local checks, including simulated Premiere markers. Actual 25.6.2 marker creation/playhead movement must be confirmed on the user's Premiere host. The previously identified color limitations remain.

Source archives examined: EditFlow-Pro-UXP-M2.6.5-Lumetri-Basic-Correction-Fix.zip and EditFlow-Pro-0.8.2-Nested-AI-Updater.zip. All supplied historical README files were read. The 0.8.2 ZIP has no README, dependency lock, Windows install entrypoint or bundled runtime; its setup.py referenced absent files. No clean-install success is claimed.

The user's correction to **25.6.2** supersedes the initial 26.5.2 request. No API introduced after 25.6.2 was added. Manifest minimum remains 25.6.2. Existing transaction and insert APIs are retained, with capability checks and host errors instead of guessed fallbacks.

## Color findings

M2.6.5 already scoped repeated labels to Basic Correction and included readback. This release strengthens, rather than invents, that implementation: stricter effect identity, new wrappers for write/readback, structured failure records, out-of-range rejection and exportable diagnostics. One matching label without section headings remains an inherited safe-uniqueness fallback; duplicate/known-other-section controls are refused. Unknown localization may be skipped.

Source frames are sampled outside Premiere: existing effects, transforms, color-space conversions, title compositing and monitor rendering are not included in the statistics. Duration-weighted averages can mix unrelated scenes. No trained coloring model is loaded. The actual trained model in this application is Whisper for speech transcription only; it does not translate Arabic into another language. Arabic language setting is transcription.

Highest Adjustment Layer affects titles beneath it. Disabled clip is detected; the report does not certify effect/section enable switches or track visibility. The decisive test remains actual FX on/off at the same Program Monitor frame.

## Integration findings

Auto Sync UXP passes source in-points as zero and labels output preview-only. AutoCut requires already aligned direct sources and creates FCP XML, not a cloned current sequence with every track/effect. SRT project import is not native caption-track creation. Caption Studio produces an alpha MOV and verifies insertion structure if the host supports it; it cannot read complete caption text from native tracks. Smart Zoom affects shared nested clips and can affect other sequences unless inner nests are independently duplicated.

No regressions are intentionally introduced to those workflows. Legacy CEP files are retained for provenance/fallback, but only the new UXP source is the forward development target. Legacy updater execution is disabled in this package; existing installed CEP code is not silently replaced.
